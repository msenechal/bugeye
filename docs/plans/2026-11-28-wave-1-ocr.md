# Wave 1 OCR: plan

**Goal:** build the OCR word map and text map layer of `docs/specs/2026-11-27-wave-1-ocr.md`: the word-level `TextReader` port, `ImageFileReader`, the portable word map (`TextMap`), find, the text map (`TextLayout`), strip reading with the 2× enlargement and timeouts, the cached identity-checked per-capture store, `LatestReading`, the Vision and ImageIO adapters and the wiring. Nothing user-visible.
**Spec:** `docs/specs/2026-11-27-wave-1-ocr.md` (approved 28 Nov 2026), on the merged contracts (`docs/specs/2026-11-27-wave-1-contracts.md`, PR #3). Where this plan and the spec differ, the spec wins unless a ruling below says otherwise.
**Branches:** one per slice, `feat/wave1-ocr-<slice>` (T16): `feat/wave1-ocr-core`, `feat/wave1-ocr-reader`, `feat/wave1-ocr-store`, `feat/wave1-ocr-wiring`. Each is cut from the previous one (stacked) and opened as a draft PR to `main`; its description says which PR it stacks on. When a lower PR merges, the next branch merges `origin/main` in.
**Ledger:** `docs/ledgers/wave-1-ocr.md`. Commit trailers: the session's Co-Authored-By and Claude-Session lines.
**PRs:** drafts while work goes on; `make test-core lint guards` is the local check and pushes are batched (R10). A PR is marked ready when its slice is done (or when the `macos` job is needed), gets a fresh final review and one fix pass for Critical and Important findings, then the parent session is told it is ready to merge.
**Process:** written and executed by the same session without approval (`design/14` R11). Ambiguities are decided and ledgered as `Ruling:`.

## Plan rulings

- **P1 — The plan lists shapes and tests, not every line of code.** As in the contracts plan (its P1): the same session writes and executes it at once (R11), and the spec fixes every public shape and rule. Every test is written and seen failing before its code. (cost if wrong: low; a fresh executor would need to write the code itself.)
- **P2 — Four slices, four stacked PRs, as spec §7:** (1) `core`: the word-level port, `FakeTextReader` reshaped, the word map, reading order, `box(for:)`, find, `mapped`, `TextLayout`; (2) `reader`: `ImageFileReader` and its fake, `StripPlan`, `PixelResample`, `TextMapReader` with timeouts, the recorded-fixture harness and the hand-made fixtures; (3) `store`: `CaptureTextMaps`, `LatestReading`, `TextLogLine`, `TextServices`; (4) `wiring`: `VisionTextReader`, `ImageIOFileReader`, `TextWiring`, `needs-mac-check`. (cost if wrong: none.)
- **P3 — `FakeTextReader` gains a fourth step, `.gate(FakeGate, [OCRLine])`:** it suspends until the test opens the gate (then returns the lines) or its task is cancelled (then throws `CancellationError`). `FakeGate` lives beside it. The store's ordering rules (Q1, Q2, Q5, Q5b) need a read the test can hold and release; `.hang` can only end by cancellation. (cost if wrong: none; additive to an OCR-owned fake.)
- **P4 — A manual test clock, `ManualClock: Clock` (`Duration`), lives in `Sources/BugeyeTestSupport/Text/`:** `advance(by:)` resumes the sleepers whose deadline has passed; `sleepers` counts them so a test can wait for a timer to be armed. (cost if wrong: none.)
- **P5 — `TextMapReader.read` takes a `beforeStrip: @Sendable () async throws -> Void` hook,** called before each strip after the cancellation check. The store passes one that throws when the mirror's URL is no longer the URL being read (Q5b). (cost if wrong: none.)
- **P6 — Any error from `ImageFileReader` other than `CancellationError` becomes `TextMapError.unreadable(url)`;** any error from `TextReader` other than `CancellationError` becomes `.recognitionFailed(String(describing: error))`. (cost if wrong: low.)
- **P7 — `map(for:)` for a capture the mirror has never seen adds the given item to the mirror,** so a capture made before the store subscribed can still be read and stored (Q6 stores only captures in the mirror). (cost if wrong: low; a deleted capture asked for later would be read once more, then dropped on its next `deleted`.)
- **P8 — `TextMap.mapped` keeps the reading order and renumbers rows densely** after dropping lines (it does not re-sort: a uniform scale and offset don't change the order). (cost if wrong: none; the reader re-runs reading order after the merge anyway.)
- **P9 — Log formats:** `<ppp>` prints without a fractional part when integral (`@2x`, `@1x`), else Swift's `description` (`@1.5x`); `<ms>` is whole milliseconds measured with `ContinuousClock`, independent of the injected timeout clock; `<error>` is `timed out on strip <n>`, `unreadable`, `recognition failed: <reader error>`, `capture gone` or `changed while reading`, never a URL or file name (§6). The ids are `CaptureID.description`. (cost if wrong: low; log text only.)
- **P10 — `TextServices` keeps the contract's `init()` (no store, `maps == nil`) until the wiring PR,** which removes it, makes `maps` non-optional and builds the real one in `TextWiring` (K7: the wiring stays a stub until the last PR). PR 3 adds `init(maps:bus:)`. (cost if wrong: none.)
- **P11 — `box(for:)` clamps the range to the line's text first;** `summary` trims spaces and tabs off the first line. (cost if wrong: none.)
- **P12 — A Q6 rerun keeps its job's priority and queue position;** a waiter whose own task is cancelled gets `CancellationError` and leaves the job, which carries on for the others (a job left with no waiter stays a background read if it was one, else it is dropped). (cost if wrong: low.)
- **P13 — A queued background job promoted by `map(for:)` takes its place among on-demand jobs at the time of promotion** ("oldest waiting on-demand request", Q2). (cost if wrong: none.)
- **P14 — Goldens (`<name>.map.json`, `<name>.txt`) are generated by the fixture test itself when `BUGEYE_UPDATE_GOLDENS=1` is set, checked by eye, and committed;** the comparison decodes and compares values, not bytes. (cost if wrong: low; a wrong golden would be reviewed in the PR diff.)

Each code task: write the tests, run the stated filter and see them fail (a compile failure for new names counts), write the code, run it again and see it pass, then `make test-core lint guards`. ## Review Focus

- Actor reentrancy in `CaptureTextMaps`: every `await` (fingerprint checks, the strip hook) can interleave with `handle`; a late result must check its generation before touching state.
- Timeouts: the group in `TextMapReader` must not leak the hanging reader task, and an outer cancellation must surface as `CancellationError`, not `timedOut`.
- `Character` offsets everywhere: NFC, emoji and combining marks in `box(for:)`, find and trimming.
- Memory: the 2× enlargement of a 1× 4000-row strip is large; `PixelResample` must not keep the source and several copies alive at once.
- Privacy: no recognised text, word or file name reaches a `TextLogLine` (errors that wrap a URL included).
- The Vision adapter's `String.Index` → `Character` offset conversion with words separated by several spaces or tabs.
